# Jarvis

In-repo movie HUD for Joseph. Run `npm run jarvis` → http://localhost:8787

Talk goes to xAI (`XAI_API_KEY` in `.env`, minted at console.x.ai — SuperGrok chat is not that key). File/HUD edits go to a local Cursor agent (`CURSOR_API_KEY`). Keys never go in the HUD or git.

When helping with school/swim/Atelier, follow `.cursor/rules/jarvis-joseph.mdc` and `JOSEPH.profile.md`.
Omit body/medical stats unless he asks. No Grok Bot default. No new subscriptions.
