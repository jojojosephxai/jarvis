# Steal (change / add)

What Joseph wants from the reels, minus the nahs. Each line is a product want, not a ticket.

1. **Launch-test skill** — MiroFish-style: stress-test a page / price / ad with simulated customers via xAI. Simpler skill, not their full repo theater.
2. **Always-on home** — a machine left on so Jarvis can live somewhere 24/7. Cloud models only — **no** local AI.
3. **Voice you already have** — keep xAI / Altair; don’t rebuild voice.
4. **HUD as the face** — Iron Man LARP screen stays central ([[Jarvis-north-star]]).
5. **Desktop pull-up proof** — show it can open/build/pull things on the desktop (capability demo, not comment-bait).
6. **Ops-brief shape (later)** — when there’s a real product: numbers → what’s working → user asks → next moves; Scout-style handoffs only after Joseph **approves the plan**.
7. **Small skills + vault memory** — single-purpose skills + markdown graph (ibraviz pattern) on *our* stack, not their kit.
8. **EOY handover** — by end of 2026 Jarvis is primary surface; **Grok Bot stays primary do-er for now** ([[Tech-setup]], [[Goals]]).

9. **Terminal pull-up animation (HUD)** — big center orb shrinks into a corner while a dark log/terminal panel slides or scales in. Build a real transition (source demo was jump-cut). From @maninalabs TikTok 2026-10-07.
10. **Self-edit with approval** — Jarvis writes the change request → Cursor cloud agent builds it → Joseph approves before merge. Show real progress (files touched, tests), not fake scrolling text.
11. **Talks while it works** — xAI voice speaks short progress lines at real milestones ("found the file", "tests passing", "ready for you to look"); orb pulses with the voice.

12. **Orb that changes shape when it talks** — a particle blob that ripples and morphs with the voice instead of spinning on its own. Motion means something. From Zoey OS reel 2026-10-08.
13. **Listening / speaking indicator** — small top-center bar: yellow LISTENING while Joseph talks, orange/cyan SPEAKING while Altair answers. Cheap win.
14. **Goodnight handoff** — Joseph says goodnight → Jarvis says what it has queued for tomorrow (real stuff: swim times, school portal due items, open tickets). Ties to daily routines (JOS-35). Outbound/writes still need plan approval.

15. **Flowy, smooth motion everywhere** — eased, fluid transitions (orb morph, panels gliding in, docking) so it feels designed, not snappy/jump-cut. Joseph 2026-10-09: "very smooth and help make it feel more designed."
