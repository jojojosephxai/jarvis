# Open the vault in Obsidian

The folder to open is `vault` (the folder, not one note inside it).

On Joseph's computer:

`C:\Users\hosef japosef\Documents\tmp-310a2048b18e7d16\vault`

1. Open Obsidian.
2. Choose **Open folder as vault**. If a vault is already open, use the vault switcher at the bottom left, then **Open folder as vault**.
3. Select the `vault` folder.
4. You should see About, Goals, Swim, School, Preferences, and a README.

Full steps and the Brain search path are in `vault/README.md`.

Brain reads this `vault` folder when you ask a question. If `OBSIDIAN_VAULT_PATH` is unset, that folder is the one it uses.
